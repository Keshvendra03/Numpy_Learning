# NumPy Basics & Practice 🧮

This repository contains a collection of Python scripts I created while learning and practicing **NumPy** (Numerical Python). It serves as a step-by-step guide from basic array creation to advanced mathematical operations.

## 📂 Topics Covered

The project is broken down into structured files, each focusing on a specific NumPy concept:

* **1_Intro.py:** Basic setup and introduction to NumPy arrays.
* **2_Multidimensional.py:** Working with 2D, 3D, and N-dimensional arrays.
* **3_Slicing.py:** Indexing, slicing, and extracting specific elements from arrays.
* **4_Arithmetic.py:** Basic mathematical operations on arrays.
* **5_Broadcasting.py:** Performing operations on arrays with different shapes.
* **6_Aggregate_Functions.py:** Using functions like `sum`, `mean`, `max`, and `min`.
* **7_Filtering.py:** Boolean indexing and conditional filtering.
* **8_Random_numbers.py:** Generating random data using NumPy's `random` module.
* **9_Reshaping.py:** Changing the dimensions and shapes of existing arrays.
* **10_Dot_product.py:** Matrix multiplication and dot products.
* **11_project.py / main.py:** Culminating practical applications using the learned concepts.
